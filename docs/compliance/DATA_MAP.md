Актуально после технической remediation на 1 августа 2026 года. Карта составлена по репозиторию, а не по догадкам о production. `НЕИЗВЕСТНО` — блокирующий факт, который должен быть подтверждён владельцем; соответствующие integrations и release сейчас fail-closed. ## Фактические хранилища и локализация

- Основная БД в коде: PostgreSQL 17, отдельная database/user/volume внутри Compose project `future-viewer`. Физический host, disk/snapshot location и страна не подтверждены.
- Redis, message broker, full-text search, user file/object storage, Sentry и analytics отсутствуют.
- Browser хранит JWT и необходимые preferences; это остаётся P1 до миграции на server-managed Secure/HttpOnly session cookies с CSRF-защитой.
- Backup scripts и isolated restore runbook добавлены, но destination, страна, key custody, schedule и первый успешный restore test неизвестны.
- До документального подтверждения РФ-локализации host/PostgreSQL/backups production release блокируется. Ни одна запись реестра с неизвестной страной не считается разрешённой.
