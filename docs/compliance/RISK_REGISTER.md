# Реестр рисков alex-taro.ru

Обновление 3 октября 2026: Telegram удалён из UI, API, фоновых служб и конфигурации. Регистрация теперь содержит один отдельный checkbox ПД; оферта/политика/18+ явно подтверждаются кнопкой «Создать», необязательные согласия выключены. Описания прежнего интерфейса и проверок ниже относятся к предыдущему состоянию. Актуальная проверка: `plans/guest-single-card-preview.md`.

Повторный аудит 25 сентября 2026 года: актуальные исправления и оставшиеся ограничения описаны в [RF_AUDIT_2026-09-25.md](RF_AUDIT_2026-09-25.md), новые проверки — в [QA_REPORT.md](QA_REPORT.md). Таблицы ниже сохраняют исходную оценку 1 августа. В частности, ранее отсутствовавшая сверка per-file manifest/SHA-256 теперь реализована, но юридические подтверждения прав по-прежнему не предоставлены.

Дата повторной оценки: 1 августа 2026 года, после технической remediation. Статусы: `OPEN` — риск остаётся; `BLOCKED` — опасная функция/release технически выключены до ручного действия; `MITIGATED` — кодовый дефект исправлен, но production/юридическая проверка ещё нужна; `RESOLVED-CODE` — требование подтверждено кодом и локальными тестами, без заявления о полном юридическом соответствии.

## Технически закрытые finding-группы

- Passwords: BCrypt hash/salt, no plaintext logging; reset/verification tokens are hashed and one-time.
- Browser rendering: all AI Markdown goes through DOMPurify; remote Google Fonts and optional analytics loaders are absent.
- Security baseline: correlation ID, CSP/HSTS/nosniff/referrer/permissions/frame protections, 1 MiB body limits and scoped rate limits.
- CI: CodeQL, Gitleaks, npm/NuGet audit, Trivy, Dependabot and release dependency graph are present.
- Deployment: exact SHA, pinned host key, non-root project path, no host-wide prune, health/isolation checks and rollback runbooks.

Эти пункты могут снова стать риском при изменении конфигурации; release gate и regression tests должны оставаться обязательными.
