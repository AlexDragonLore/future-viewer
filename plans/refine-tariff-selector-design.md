# Дизайн выбора тарифа

## Реализация

- Переделать общий блок оплаты на главной и в профиле: компактные карточки «Неделя» и «Месяц», заметная цена, спокойный индикатор выбора и одна кнопка оплаты.
- Уменьшить количество конкурирующих рамок, выровнять отступы и заменить капс и декоративный шрифт внутри формы на читаемую типографику.
- Сохранить доступные radio inputs, обязательное согласие с офертой, блокировку повторного платежа и выбор тарифного кода.

## QA / verification

- Выполнить `npm run type-check`, существующие компонентные тесты оплаты и `npm run build`.
- Проверить главную и профиль в Playwright на 320–1280 px: оба тарифа, сумма, согласие, отправляемый код и отсутствие переполнения.
- Выполнить rendered QA в in-app browser; авторизованные страницы покрыть локальными API-фикстурами Playwright. Просмотреть скриншоты в контексте страницы и блока оплаты.
- Backend не меняется; повторный `dotnet test` не требуется. Публикация не запрошена.

## Результаты

- `npm run type-check`, `npm test` (283 теста), `npm run build` и `git diff --check` прошли.
- 46 Playwright-сценариев Chromium/mobile Chromium прошли; проверены выбор обоих тарифов, согласие, запрос оплаты, переносы текста и отсутствие переполнения.
- In-app browser: просмотрены обычная ширина и 320 px, подтверждено переключение стрелкой на клавиатуре.
- Просмотрены реальные страницы с API-фикстурами: профиль 393 px и главная 1280 px. Скриншот профиля сохранён в `frontend/test-results/refined-tariffs-preview.png`.
