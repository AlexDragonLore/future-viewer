# Тарифы на 7 и 30 дней

## Реализация

- Добавить серверный тариф `pro-7d`: 99 ₽, 7 дней. Изменить `pro-30d`: 299 ₽, 30 дней.
- Публиковать оба тарифа в публичной конфигурации. При создании платежа принимать код тарифа и выбирать цену и срок на сервере.
- Передавать выбранную сумму платёжному провайдеру и сохранять условия в заказе. Сохранить обработку ранее созданных заказов по их исходным условиям.
- Добавить выбор тарифа в общий компонент оплаты на главной и в профиле, обновить описание продления и настройки Docker/env.
- Сохранить существующие локальные изменения; коммит и публикация не запрошены.

## QA / verification

- Проверить backend-тестами создание обоих тарифов, отклонение неизвестного кода, сумму у обоих провайдеров и продление на выбранный срок.
- Выполнить `dotnet test` для затронутых тестов; интеграционные проверки требуют Docker.
- Выполнить `npm run type-check`, `npm test`, `npm run build`.
- Проверить выбор и отправку тарифа в компонентных тестах, мобильную раскладку и состояние продления — в браузерных тестах.
- Выполнить rendered QA в доступном in-app browser для главной и профиля; при недоступности авторизованного состояния использовать локальные API-фикстуры и Playwright.

## Результаты проверки

- `npm run type-check`, `npm test` (283 теста) и `npm run build` прошли.
- Backend: 45 тестов `SubscriptionServiceTests` и 48 интеграционных тестов провайдеров, subscription/public endpoints, статуса и конкурентной обработки платежей прошли с Docker/Postgres.
- Playwright: 23 сценария Chromium и 23 сценария mobile Chromium прошли; проверены главная и профиль с локальными API-фикстурами, ширины 320–1280 px, обе суммы, выбор тарифа, принятие оферты и тело запроса оплаты.
- In-app browser: общий компонент оплаты проверен на локальных данных при обычной ширине и 320 px, переключение тарифа подтверждено. Авторизованные страницы проверены в Playwright с фикстурами; реальные платежи не выполнялись.
- JSON/YAML и обе конфигурации Docker Compose валидны; `git diff --check` прошёл.
- Изменения локальные, публикация не запрашивалась.
